# x402 public agent runs (Week 3)

Unauthenticated callers pay once (MockUSDC on BSC Testnet **97**), then call the public run API.  
**Cooker UI keeps using SIWE `POST /agent/runs` for free.**

## Endpoint

`POST /agent/public/runs`

Body (same shape as SIWE runs):

```json
{
  "goal": "Saya mau masak ayam semur",
  "pantry": ["chicken", "onion"],
  "selectedDish": "Ayam Semur"
}
```

## Payment flow

1. Client calls without payment proof → **HTTP 402** + `accepts` JSON (`payTo`, `amount` atomic mUSDC, `chainId` 97, `token` = `MOCK_USDC_ADDRESS`).  
2. Client transfers MockUSDC to `X402_PAYTO` for at least `X402_PRICE`.  
3. Client retries with header **`X-PAYMENT-TX: 0x…`** (32-byte tx hash).  
4. Server verifies on-chain Transfer to `X402_PAYTO` ≥ price, **consumes the tx once**, runs CommerceAgent → returns `{ ok, runId, status, intent, steps, suggestions?, plan?, quote?, … }`.  
5. Reusing the same tx → **HTTP 409** (`payment_replay`).

This is a **minimal x402-style gate** (plain ERC-20 `transfer`). Official `@x402/express` facilitator / ERC-3009 is out of scope for MockUSDC on BSC testnet.

Agent fee (`X402_PAYTO`) is **not** the warung quote `payTo` — those are separate payments.

## Env

```env
X402_ENABLED=true
X402_PAYTO=0x9389afdD7Ae5729BcCD2DFeac738b8bFd6110a74
X402_PRICE=10000
MOCK_USDC_ADDRESS=0x...
BSC_RPC_URL=https://data-seed-prebsc-1-s1.bnbchain.org:8545
CHAIN_ID=97
```

`X402_PRICE` is **atomic** (6 decimals). `10000` = 0.01 mUSDC.  
Default treasury matches ERC-8004 `agentWallet`. Kill switch: omit or set `X402_ENABLED=false` → **503**.

## Demo script

From repo root (needs `DEMO_PAYER_PRIVATE_KEY` + mUSDC/tBNB on that wallet):

```bash
# Against local or hosted API
API_URL=http://localhost:4100 npm run demo:x402
# or
API_URL=https://botlevy-commerce-production.up.railway.app npm run demo:x402
```

Logs steps: unpaid **402** → agent-fee tx → **quoted** lines/total → replay **409**.

## Curl

```bash
# Expect 402
curl -sS -X POST "$API/agent/public/runs" \
  -H 'content-type: application/json' \
  -d '{"goal":"I want to cook ayam semur tonight","pantry":["salt"]}'

# After paying on-chain:
curl -sS -X POST "$API/agent/public/runs" \
  -H 'content-type: application/json' \
  -H 'X-PAYMENT-TX: 0xYourTxHash' \
  -d '{"goal":"I want to cook ayam semur tonight","pantry":["salt"]}'
```

## Security

| Control | Detail |
|---------|--------|
| Kill switch | `X402_ENABLED=true` |
| Rate limit | 10 req / min / IP on this route |
| Body caps | Same zod limits as SIWE runs |
| Tx format | `^0x[a-fA-F0-9]{64}$` |
| Replay | Spent hashes in `runtime.json` |
| CORS | Open (`*`) for `/agent/public/runs` and metadata — no cookies |
| Response | Steps stripped of LLM I/O unless `LLM_TRACE` |
